## 实践陪练 Android App

用户输入目标，应用结合现有材料、设备和经验提供步骤指导，并接收图片或短片反馈。覆盖烹饪烘焙、摄影与相机运镜、软件技能、咖啡饮品。

当前阶段为产品规格与开发规划，尚未实现应用代码。主要代码由华为云码道 Agent Space 编写，Codex 负责审查。

- 文档索引：[docs/README.md](docs/README.md)
- 七天计划：[docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md)
- 码道任务：[docs/CODEARTS_PROMPTS.md](docs/CODEARTS_PROMPTS.md)

服务端本地配置使用 `server/.env`（不提交）；可从 `server/.env.example` 创建。APK、源码、日志和证据材料不得包含密钥。构建和运行步骤将随实现阶段验证更新。
