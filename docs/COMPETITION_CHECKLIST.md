## 3. PPT 10 页大纲

1. **封面**：实践陪练 / tutorial-coach；一句话“把目标变成可执行、可反馈、可记录的练习”；队伍/学校/日期。
2. **问题**：教程看完仍不会做；步骤断点、条件不匹配、缺少反馈、失败无法复盘。
3. **产品**：目标入口 + 参考教程 + 四领域；澄清→计划→步骤→反馈→修订→记录闭环。
4. **四领域演示**：烹饪番茄鸡蛋面、摄影咖啡环绕、Windows 11 照片整理、V60 手冲；每领域一张真实截图。
5. **AI 能力**：DeepSeek 文本/视觉；结构化计划/反馈；证据分级；不确定性；不编造。
6. **运镜与配方**：CameraMoveSpec 路径/Canvas 动画；咖啡配方版本/单变量/历史对比。
7. **架构**：Kotlin/Compose + FastAPI + DeepSeek + ffmpeg；Key 仅服务端；Job/轮询；本地 JSON。
8. **可靠性与边界**：超时/限流/坏 JSON/媒体失败恢复；无实时相机/无音频分析/2D 示意/不判断内部温度与口味。
9. **码道证据**：分阶段 Prompt、生成/调试/重构记录、测试/构建日志、Codex 审查；不伪造。
10. **价值与路线**：从“看教程”到“练会”；后续领域扩展/云部署/更多动画；比赛提交信息。

**PPT 红线**：不写“100% 准确”“保证七天完成”“模型已验证视频输入”；不贴 Key/个人信息/未脱敏日志；截图必须来自真实运行。

## 4. 3 分钟视频脚本（≤3:00）

| 时间 | 画面 | 旁白/字幕 |
|---|---|---|
| 0:00–0:15 | 标题 + 问题 | “教程很多，真正动手时还是卡住。实践陪练把目标变成可执行步骤。” |
| 0:15–0:45 | 输入“2 人份番茄鸡蛋面，30 分钟”，回答问题，生成计划 | “先问清材料、灶具、时间、人数；计划含准备清单、时间、可观察完成标准。” |
| 0:45–1:15 | 步骤卡、计时、暂停、提问、修改条件 | “随时提问、暂停、改条件；有进度后不覆盖已完成步骤。” |
| 1:15–1:45 | 上传菜品照片/短片，反馈证据与补救 | “只陈述有证据的观察；不判断内部温度/食用安全；不足就说不确定。” |
| 1:45–2:15 | 摄影环绕运镜路径/动画，上传短片反馈 | “区分机位移动与镜头朝向；结构化参数，不执行模型代码；短片带时间戳、不分析音频。” |
| 2:15–2:40 | 咖啡配方 tasting/单变量/历史对比 | “口味只来自用户；一次只改一个变量；配方历史可回查。” |
| 2:40–3:00 | 架构/证据/限制/结尾 | “Key 仅在服务端；失败有恢复；码道生成与调试痕迹可查。实践陪练，让练习真正发生。” |

录制清单：

- 真机/模拟器真实操作，不剪辑成虚假成功；失败路径可保留 1 个（显示恢复）。
- 不出现 Key、账号、通知、个人照片、其他项目窗口。
- 分辨率 1080p，横屏；总长 ≤3:00；字幕不遮挡 UI。
- 若某能力未通过真实闸门，视频不演示该能力，PPT/README 明确“未验证/未启用”，不得用静态动画冒充。

## 5. README 必需章节

1. 项目简介与四领域演示目标。
2. 环境要求：Windows 11、JBR 21、Android SDK、Gradle、Python 3.12、ffmpeg 7；不要求 Android Studio。
3. 服务端：`python -m venv`、依赖、`.env` 配置（只写变量名/占位符）、`uvicorn`、`/v1/health`。
4. Android：会话级 `JAVA_HOME`、`assembleDebug`、APK 路径、`adb install`、启动。
5. 联调：`adb reverse tcp:8000 tcp:8000`；手机访问 `http://127.0.0.1:8000`；无 USB 的 LAN 回退与风险。
6. 四个演示任务步骤（真实可跑）。
7. 能力与限制：无实时相机、视频≤30s/≤100MiB、音频不分析、2D 运镜示意、图片不判断内部温度/口味、参考教程边界。
8. 隐私与 Key：Key 仅服务端；日志脱敏；媒体保留期/删除；不提交 `.env`/个人媒体。
9. 排错：无 Key、401/402/429、超时、坏 JSON、ffmpeg 缺失、无设备、build-tools 缺失。
10. 证据/目录：`docs/`、`contracts/`、`codearts_proof/`；比赛提交说明。

**README 红线**：不写“APK 独立运行/无需服务端”；不写未验证模型/视频能力；不把本地演示说成公网服务。

## 6. 一键脚本与验收

| 脚本 | 作用 | 验收 |
|---|---|---|
| `setup-server.ps1` | 创建 `.venv`、安装锁定依赖、复制 `.env.example`（不填 Key） | 幂等；不覆盖已有 `.env`；无 Key 输出 |
| `run-server.ps1` | 启动 uvicorn 127.0.0.1:8000 | `/v1/health` 200；Ctrl+C 可退出 |
| `build-apk.ps1` | 设置会话级 JBR 21、`assembleDebug` | APK 路径打印；失败非零退出 |
| `install-apk.ps1` | `adb install -r` + 启动 | 无设备明确报错；不假装成功 |
| `verify-submission.ps1` | 检查 Key/`.env`/构建垃圾/APK/视频时长/材料 | 失败非零退出；输出检查项 |

脚本约束：不嵌入 Key；不修改系统 `JAVA_HOME`/PATH；不自动安装 SDK/系统镜像；不自动报名/提交。

## 12. 常见退回/扣分风险

- 把 Web/PWA/WebView 当 Android App → 直接不符合；本项目用原生 Kotlin/Compose。
- 静态演示/假模型结果 → 证据与现场复跑会暴露；所有演示必须真实。
- 视频/截图含 Key/个人信息 → 安全违规；提交前扫描。
- 声称未验证能力（视频输入、精确评分、音频理解） → 评审质疑；明确限制。
- 材料缺 README/依赖/一键脚本/码道证据 → 按清单补齐。
- 截止日期误判（按 11/18 拖延） → 按 11/17 前完成。
